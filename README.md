# זמני נצח

כלי אישי ליצירת לוח זמני כניסת ויציאת שבת (וחגים וצומות) לזכר יקיריכם.

**האתר החי:** https://idoyan-spec.github.io/Zmanei_Nezach/

## מה הכלי עושה
- אשף קצר של 6 צעדים: תמונה (עם זום ומיקום ותצוגה מקדימה חיה) → פרטי הנצחה → משפט לזיכרון → בחירת ערים (עד 8; רשימת 1,174 יישובי ישראל מוטמעת בכלי, ולחו״ל חיפוש חי) → בחירת עיצוב (12 תבניות ב-2 קבוצות + 4 גווני צבע) → סגנון כתב (5 זוגות גופנים).
- ההגדרות והתמונה נשמרות **רק בדפדפן שלכם** (localStorage) — שום דבר לא נשלח לשרת.
- מכל כניסה: בוחרים תאריך, לוחצים "צור לוח", ומקבלים תמונת PNG מעוצבת (1254×1254) לשיתוף/הורדה.
- זיהוי אוטומטי של שבת / חג / צום / יום כיפור לפי התאריך שנבחר.

## מקורות הזמנים
הזמנים מחושבים באמצעות [Hebcal](https://www.hebcal.com/) — חישוב אסטרונומי לפי קואורדינטות כל עיר.
מנהגי הדלקת נרות: ירושלים 40 דק' לפני שקיעה, חיפה 30, שאר הערים 18. צאת שבת/חג: צאת הכוכבים.
הזמנים הם עזר בלבד — הלכה למעשה מומלץ לאמת מול לוח הרבנות המקומית.

## פיתוח
- סטטי לחלוטין (HTML/JS Canvas, ללא build). בדיקה מקומית: `python -m http.server 8631` ולפתוח `http://127.0.0.1:8631/`.
- מצב דמו לבדיקות: `/?demo=1&auto=1&date=YYYY-MM-DD&tpl=<שם תבנית>&font=<זוג גופנים>&tone=<גוון>`. איפוס האשף: `/?reset=1`.
- גופנים: David Libre + Gveret Levin + Frank Ruhl Libre (מקומיים, OFL) + Suez One / Bellefair / Secular One / Heebo / Amatic SC (מ-Google Fonts).
- חיפוש ערים: `cities-il.json` מוטמע (1,174 יישובים, ~21KB דחוס, מקור data.gov.il) ונסרק מקומית עם נורמליזציה של כתיב מלא/חסר; לחו״ל Open-Meteo; ורק כמוצא אחרון Nominatim/OpenStreetMap — שמדיניותו מגבילה לבקשה אחת לשנייה **לכל אפליקציה** ואוסרת חיפוש-תוך-כדי-הקלדה. אזור הזמן נגזר מהקואורדינטות.
- נכסים: התבניות ב-WebP — ממוזערת 320px לגלריה ומלאה 1254px רק לנבחרת. ביקור ראשון ~124KB במקום 7.26MB.
- קובץ הגדרות: ייצוא/ייבוא JSON מחליף חשבון משתמש — אין שרת ואין הרשמה.
- רקעי התבניות נוצרו ב-Gemini ללא טקסט; כל הטקסטים, התמונה והלוחית מצוירים בקוד על Canvas.
