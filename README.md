# לוח שבת לזכרם

כלי אישי ליצירת לוח זמני כניסת ויציאת שבת (וחגים וצומות) לזכר יקיריכם.

**האתר החי:** https://idoyan-spec.github.io/luach-shabbat-lezichram/

## מה הכלי עושה
- אשף קצר של 5 צעדים: תמונה → פרטי הנצחה → משפט לזיכרון → בחירת ערים (עד 8) → בחירת עיצוב (4 תבניות).
- ההגדרות והתמונה נשמרות **רק בדפדפן שלכם** (localStorage) — שום דבר לא נשלח לשרת.
- מכל כניסה: בוחרים תאריך, לוחצים "צור לוח", ומקבלים תמונת PNG מעוצבת (1254×1254) לשיתוף/הורדה.
- זיהוי אוטומטי של שבת / חג / צום / יום כיפור לפי התאריך שנבחר.

## מקורות הזמנים
הזמנים מחושבים באמצעות [Hebcal](https://www.hebcal.com/) — חישוב אסטרונומי לפי קואורדינטות כל עיר.
מנהגי הדלקת נרות: ירושלים 40 דק' לפני שקיעה, חיפה 30, שאר הערים 18. צאת שבת/חג: צאת הכוכבים.
הזמנים הם עזר בלבד — הלכה למעשה מומלץ לאמת מול לוח הרבנות המקומית.

## פיתוח
- סטטי לחלוטין (HTML/JS Canvas, ללא build). בדיקה מקומית: `python -m http.server 8631` ולפתוח `http://127.0.0.1:8631/`.
- מצב דמו לבדיקות: `/?demo=1&auto=1&date=YYYY-MM-DD&tpl=classic|olive|jerusalem|night`. איפוס האשף: `/?reset=1`.
- גופנים: David Libre + Gveret Levin + Frank Ruhl Libre (כולם OFL).
- רקעי התבניות נוצרו ב-Gemini ללא טקסט; כל הטקסטים, התמונה והלוחית מצוירים בקוד על Canvas.
